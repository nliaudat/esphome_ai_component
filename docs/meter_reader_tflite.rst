meter_reader_tflite
====================

**Status: Active (v2.0+)**

The ``meter_reader_tflite`` component is the primary AI-powered meter reader
using TensorFlow Lite Micro models. It orchestrates camera capture, inference,
digit recognition, and result publishing.

Requires ESPHome **2026.11** or later.

Model configuration lives in :doc:`tflite_micro_runtime`: the model is declared
once in a ``tflite_micro_runtime`` entry and referenced by ID from
``meter_reader_tflite``. The component no longer loads models itself.

Configuration
-------------

.. code-block:: yaml

    # 1. Declare the model once (input shape/arena size read from the model)
    tflite_micro_runtime:
      - id: my_digit_model
        model: "models/digit_recognizer_v40_quantized_integer_quant_uint8.tflite"
      # debug: true                 # verbose model logging
      # tensor_arena_size: "110KB"  # override the estimate

    # 2. Rotate the image before inference, if the camera is mounted sideways
    esp32_camera_utils:
      id: my_camera_utils
      camera_id: my_camera
      enable_rotation: true
      rotation: 90.0

    # 3. Reference the model by ID
    meter_reader_tflite:
      id: my_meter
      model: my_digit_model          # ← ID reference to the runtime entry
      camera_id: my_camera
      validator: my_validator
      confidence_threshold: 0.85
      update_interval: 60s

      flash_light_controller: my_flash
      data_collector: my_collector
      collect_low_confidence: true
      collect_min_global_confidence: 0.90
      collect_min_digit_confidence: 0.90
      frame_request_timeout: 15000

      value_sensor: my_value
      confidence_sensor: my_confidence
      inference_logs: my_logs
      debug: false
      debug_image: false

Migrating from the old syntax
-----------------------------

The following options were removed from ``meter_reader_tflite`` because they
belong to the model or to the camera:

.. list-table::
    :header-rows: 1

    * - Removed option
      - Where it lives now
    * - ``model: "file.tflite"`` (direct file)
      - Removed. Declare the model in ``tflite_micro_runtime`` and use
        ``model: <runtime_id>``.
    * - ``tensor_arena_size``
      - ``tflite_micro_runtime`` entry.
    * - ``input_type``, ``input_channels``, ``input_width``, ``input_height``,
        ``output_processing``, ``scale_factor``, ``input_order``, ``normalize``,
        ``invert``
      - ``tflite_micro_runtime`` entry (read from the model when omitted).
    * - ``rotation``
      - ``esp32_camera_utils`` (``rotation`` + ``enable_rotation``).
    * - ``raw_data_id``
      - Generated by ``tflite_micro_runtime``; no longer a user option.

Configuration variables
-----------------------

- **id** (*Required*): The ID of this component.
- **model** (*Required*): ID of the ``tflite_micro_runtime`` entry that defines
  the model.
- **camera_id** (*Optional*): The ID of the ``esp32_camera`` component. Required
  on ESP32.
- **validator** (*Optional*): The ID of a ``value_validator`` component.
- **confidence_threshold** (*Optional*): Minimum confidence to publish a
  reading, 0–1. Defaults to ``0.85``.
- **update_interval** (*Optional*): Polling interval. Defaults to ``60s``.
- **camera_resolution** (*Optional*): Resolution string (e.g. ``640x480``) that
  must match ``esp32_camera.resolution``. Defaults to ``640x480``.
- **frame_request_timeout** (*Optional*): Camera frame request timeout in ms,
  1000–60000. Defaults to ``15000``.
- **show_crop_areas** (*Optional*, boolean): Draw the crop zones on the preview
  image. Defaults to ``true``.
- **generate_preview** (*Optional*, boolean): Serve a ``/preview`` image (crop
  areas drawn) from the web server. Defaults to ``false``.
- **enable_flash_calibration** (*Optional*, boolean): Enable the flash
  calibration mode. Defaults to ``false``.
- **start_flash_calibration_button** (*Optional*): Button ID used to start a
  flash calibration.
- **unload_button** / **reload_button** (*Optional*): Button IDs that unload or
  reload the model at runtime.

**Integration**

- **flash_light_controller** (*Optional*): ID of a ``flash_light_controller``;
  the flash is enabled around each capture.
- **data_collector** (*Optional*): ID of a ``data_collector``; images of
  uncertain readings are uploaded for training.
- **collect_low_confidence** (*Optional*, boolean): Upload when confidence is
  below ``confidence_threshold``. Defaults to ``true``.
- **collect_min_global_confidence** (*Optional*): Lower bound for the global
  confidence used by the data collector, 0–1. Defaults to ``0.90``.
- **collect_min_digit_confidence** (*Optional*): Lower bound for the
  per-digit confidence used by the data collector, 0–1. Defaults to ``0.90``.
- **crop_zones_global** (*Optional*): ID of a ``globals`` component holding the
  crop-zone JSON string.

**Entities**

- **value_sensor** (*Optional*): Sensor that receives the reading.
- **confidence_sensor** (*Optional*): Sensor that receives the confidence (%).
- **inference_logs** / **main_logs** (*Optional*): Text sensors that receive the
  inference and component logs.

**Diagnostics**

- **debug** (*Optional*, boolean): Verbose component logging. Defaults to
  ``false``. For model-level logging, set ``debug: true`` on the
  ``tflite_micro_runtime`` entry instead.
- **debug_image** (*Optional*, boolean): Run inference on the bundled static
  test image instead of the camera. Defaults to ``false``.
- **debug_image_out_serial** (*Optional*, boolean): Dump the processed image to
  the serial port. Defaults to ``false``.
- **debug_camera** (*Optional*, boolean): Verbose ``esp32_camera_utils``
  logging. Defaults to ``false``.
- **debug_timing** (*Optional*, boolean): Publish/log timing breakdowns.
  Defaults to ``false``.
- **debug_memory** (*Optional*, boolean): Log memory statistics and create the
  diagnostic sensors below. Defaults to ``false``.
- **tensor_arena_size_sensor**, **tensor_arena_used_sensor**,
  **process_free_heap_sensor**, **process_free_psram_sensor**,
  **pool_job_efficiency_sensor**, **pool_result_efficiency_sensor**,
  **arena_efficiency_sensor**, **heap_fragmentation_sensor**,
  **total_inference_time_sensor**, **capture_to_publish_time_sensor**
  (*Optional*): Sensor IDs that receive the corresponding diagnostics. With
  ``debug_memory: true`` the arena/heap sensors are created automatically, so
  these keys are only needed to point at your own sensors.

Performance
-----------

On ESP32-S3 with an optimized model, the full pipeline (capture + inference)
completes in **under 270ms**. On classic ESP32, expect under 2700ms.

Dependencies
------------

- ``tflite_micro_runtime`` (required)
- ``esp32_camera`` (required)
- ``esp32_camera_utils`` (auto-loaded)
- ``value_validator`` (optional)
- ``flash_light_controller`` (optional)
- ``data_collector`` (optional)
